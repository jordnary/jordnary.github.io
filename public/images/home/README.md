# Home artwork

The Directory and Now & notes galleries use six optimized WebP images encoded from supplied artwork at 1536 × 1024, without EXIF, XMP or ICC metadata:

- `about.webp`: an iceberg and a path into a hidden library.
- `learning.webp`: an architectural library with orange circulation paths.
- `projects.webp`: a sketching desk.
- `contact.webp`: lavender stationery and a paper airplane.
- `now-building.webp`: a wooden studio with climbing plants and pencil construction lines.
- `now-following.webp`: a nature scrapbook, paper cutouts and a magnifying glass.

The reader uses `now-woodland-frame.webp` in a 3:2 layout on every screen size. Its depth of field is part of the artwork; no browser blur is required. `repository-flourish.webp` supplies the transparent lower-edge ornament on repository entries.

Production uses the WebP files. Layout, interaction constraints and checks are documented in `docs/design/home-now-reader.md`.
