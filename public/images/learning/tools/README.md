# Learning toolkit icons

The original-color SVG marks are from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), distributed under the [MIT license](./LICENSE.devicon.txt).

Included marks: Python, PyTorch, React, TypeScript, JavaScript, Git, HTML5, CSS3 (shown as CSS), Julia, C++, and Docker. Brand marks remain the property of their respective owners. These local assets identify the tools used in the learning projects.

The toolkit displays the original SVG artwork with a grayscale filter at rest. Hovering or keyboard focus removes the filter to reveal each mark's original palette, including Python's blue and yellow and Julia's three colored circles. Names use a matching brand color with separate shades for light and dark backgrounds.
