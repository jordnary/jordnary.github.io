# Projects archive background

The artwork is based on the supplied grayscale line drawing. The page uses two processed WebP variants:

| Asset | Dimensions |
| --- | --- |
| `linework-background-1920.webp` | 1920 × 1081 |
| `linework-background-3840.webp` | 3840 × 2161 |

The original 1672 × 941 image remains as `linework-background.webp`. The variants preserve the composition, unify paper highlights at `#f2f2f2`, and reduce line contrast. Resampling improves display sampling without adding source detail. Source metadata is omitted.

The archive uses a fixed, full-viewport background. Hover previews use the existing project covers in their original 8:5 proportions without cropping.
