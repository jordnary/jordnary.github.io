**焦点修复。** 快速用键盘从一个导航菜单移向另一个控件时，上一菜单可能在下一动画帧抢回焦点。现在只有触发控件仍持有焦点、目标面板也仍可见时才交接焦点；针对“同一帧已经移开”和正常打开都做了断言。本次不改菜单布局、动画或路由加载。

其余初验差异属于测试观察时机。现在先等项目菜单实际画出再用 Escape 中断；字体分开断言页面主动准备的 3 段与真正产生传输的切片（浏览器重载时还可能从缓存取用其他字体）；真实标签恢复检查等待出现新的绘制帧，同时仍要求没有重复循环。正向预取用例提供确定的调度机会，另有一直无空闲仍可立即导航的用例。没有为通过测试而让产品强制预取。
