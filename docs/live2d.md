# Live2D 看板娘

第一版在共享的 `SiteLayout` 中接入，覆盖首页、关于、学习、项目和联系页面。

## 显示与交互

- 桌面端首次访问默认展开，位于右下角，距离底部 `1rem`，另加设备安全区。
- 人物画布最大约 `200 × 280px`，随窗口缩放；按实际渲染的透明度边界校正模型留白，保留完整人物。
- 小于 `768px` 或主要使用触摸操作的设备默认收起；手动展开后的画布为 `160px` 宽、最高 `224px`。手机每次进入页面仍默认收起。
- 鼠标控制视线和头部轻微转动；待机循环使用模型原有的眨眼、呼吸和物理效果。
- 点击人物或「聊聊」切换本站编写的短句，并播放摸头动作；台词在五秒后消失。台词不是原游戏台词，也不包含语音。
- 收起会卸载画布、停止动画并释放 GPU 资源。桌面收起偏好保存在浏览器中，存储不可用时也能使用。
- 画布不拦截网页点击，点击下方链接、按钮、输入框或选择文字时不会触发台词。
- 打开站内搜索时隐藏并暂停；复制提示出现时暂时隐藏；切换到后台暂停动画。开启系统「减少动态效果」时显示静态人物。
- 独立的「返回顶部」按钮及其样式已移除，不再为其预留空间；后续页面联动可从看板娘入口扩展。
- 加载失败时显示「再试一次」，用户也可以直接收起。

## 资源与运行库

运行所需资源位于 `public/live2d/vampire`。来自用户提供的 `downloads` 资源，仅选用模型、贴图、物理配置、待机和摸头动作；不重复发布原始压缩包和其余动作。原始文件保持不变。

模型为吸血鬼（Vampire）的 `xixuegui_4`。来源与原有使用范围见随模型提供的 `SOURCE.md`，沿用用户已确认的非商业、非盈利个人网站用途，不扩展授权范围。

- [模型来源页面](https://l2d.su/cn/skins/201233/)
- [pixi-live2d-display 文档](https://guansss.github.io/pixi-live2d-display/)
- [Live2D Cubism SDK for Web](https://www.live2d.com/sdk/download/web/)

PixiJS 与适配库由 npm 锁定版本并按需打包。Cubism Core 在展开时从 Live2D 官方地址加载，有十五秒超时与重试；首次展示依赖该地址可达。手机保持收起时不请求 Core、渲染库或模型资源。适配库携带的发布工具通过 `overrides` 更新到已修复版本，不参与页面运行。

## 常用调整

- 尺寸、位置、气泡和入口样式：`src/components/Live2DCompanion.css`。
- 台词、展开策略与页面交互：`src/components/Live2DCompanion.tsx`。
- 加载、模型缩放、视线强度、帧率和销毁：`src/lib/live2d.ts`。
- 模型与动作映射：`public/live2d/vampire/model.model3.json`，其中 `Idle` 对应原始 `idle`，`Tap` 对应 `touch_head`。

## 验证

运行 `npm run build` 与 `npm run lint`。浏览器检查桌面和手机的默认状态、人物点击、台词切换、展开/收起、桌面偏好恢复、搜索避让、深浅主题，以及页面滚动后人物和原有控件能否正常操作。
