# Live2D 看板娘

看板娘在共享的 `SiteLayout` 中接入，覆盖首页、关于、学习、项目和联系页面。

站内普通链接通过 History API 切换正文，保留同一个共享布局、看板娘画布和模型实例；导航栏、首页入口、页脚和搜索结果均适用。板块切换不会重新请求模型、重播 `home` 或打断正在播放的动作。浏览器前进 / 后退同步页面并恢复滚动位置，跨页锚点、标题、描述和导航选中项同步更新。各页面继续保留独立 HTML 入口，直接访问和刷新正常；外链、下载、新标签页及带修饰键的点击保留浏览器行为。

## 显示与尺寸

- 手机端默认收起：小于 `768px`、主要指针为触摸或不支持悬停时，保留展开入口，点击后才请求渲染库、Cubism Core 和模型资源。手机端的展开状态通过 `sessionStorage` 在当前标签页会话中独立保存，刷新后保留，关闭标签页后正常重新打开恢复默认收起，不影响桌面状态。功能列按钮为 `32 × 32px`，SVG 为 `12 × 12px`；展开加载完成时短暂显示，触摸人物区域或操作工具栏后重新计时，约 `3s` 无操作后自动隐藏。触摸页面其他位置、滚动或取消触摸会提前隐藏；隐藏后再次触摸人物区域即可唤出，页面原有控件保留优先级。
- 桌面默认展开；收起状态通过 `sessionStorage` 保存，刷新后保留，关闭标签页后正常重新打开恢复默认展开，旧版 `localStorage` 保存的收起偏好不再生效。浏览器的恢复已关闭标签页或会话恢复功能可能同时恢复会话状态。收起会卸载画布、停止动画并释放 GPU 资源，右下角保留一个 `44 × 44px` 的小图标用于恢复，距内容视口右侧和底部各 `24px`（另计设备安全区），独立于展开时的定位。
- 人物布局基准宽度为 `clamp(12rem, 18vw, 15rem)`，即约 `192–240px`；高度为 `min(21rem, 46svh)`，上限约 `336px`。按参考图缩至此前约七成，短窗口随可用高度等比缩小。
- 按实际渲染透明度校正模型导出留白，等比显示完整模型。气泡从可见模型整体中心向左微调模型宽度的 `8%`，对齐人物主体上方，底边距离模型上沿约 `10px`；宽度上限 `200px`，并随可见模型宽度收窄，文字为 `13px`。窗口尺寸变化时同步更新定位，不挤占人物高度或超出右侧视口。
- `home` 和 `idle` 在启动动作前统一用默认姿态校准尺寸与定位，避免 `home` 首帧只有背景时错误放大人物。两段动作使用相同缩放和画布，直接自然衔接；不追加缩放过渡，保持人物、工具栏或气泡布局不变。实际画布单独向左扩展可见模型宽度的 10%（常用尺寸约 23px），容纳完整 idle 循环的左侧摆动；绘制坐标作反向补偿，不放大或移动人物。允许超出 idle 范围的出场特效短暂越界。
- 功能列放在人物右下侧的透明区域，不在画布外额外占位；距画布右侧 `16px`、底边 `8px`。画布距离内容视口右侧 `2px`、下侧 `6px`（另计设备安全区），相对此前向右移动 `4px`，模型在画布内靠右下对齐。
- 搜索打开时隐藏并暂停；复制提示出现时隐藏且不接受人物交互；窗口转入后台暂停。系统减少动态效果设置会停用人物动画及控件过渡。

## 严格的聊天触发范围

鼠标命中以当前姿态的语义部件为准，并要求实际渲染 alpha 不低于 `24/255`：

- **摸头**：模型自带 `TouchHead` 三角网格与实际头部可见像素的交集，触发 `touch_head`。
- **胸部**：模型自带 `TouchSpecial` 三角网格与实际身体可见像素的交集，触发 `touch_special`。
- **其他部位**：其余身体、服装和四肢的可见像素，触发 `touch_body`；键盘 `Enter` / 空格同样触发该动作。

模型原始 `TouchBody` 矩形包含大量背景，因此不采用它作为身体范围。实际部件按导出的父级关系识别，优先识别 `shenti`，再识别 `tou`；模型把身体嵌套在头部层级下，不能简单地把 `tou` 的所有后代都算作头部。另按逐网格预览结果排除混在身体与面部层级里的翅膀、翼骨、长飘带和手持装饰。背景、外围装饰、透明孔洞和 CSS 阴影不触发反应。

一次有效聊天需要同时满足：

1. 主要鼠标指针的左键单击，未按 `Ctrl`、`Meta`、`Alt`、`Shift`，且事件未被网页取消。
2. 按下和单击完成时均命中同一语义区域；中途移动不得超过 `6 CSS px`。在头部、胸部、其他身体区域之间滑动、拖出再拖回、滚动和指针取消都会终止候选点击。
3. 没有选中的页面文字，且目标不是链接、按钮、输入框、可编辑区、可通过 Tab 访问的自定义控件或常用 ARIA 交互控件。仅用于导航后聚焦正文的 `main[tabindex="-1"]` 不阻止人物点击；链接、按钮及 ARIA 交互控件即使设置 `tabindex="-1"` 仍保留优先级。
4. 人物点击对话已开启，看板娘已经加载、未被搜索或复制提示隐藏，且页面处于可见状态。

画布保持点击穿透，网页原有控件保留优先级。命中时通过 Pixi 与 Cubism 的逆变换换算坐标，使用当前帧网格；通过短暂隔离语义部件的渲染透明度排除背景，包含贴图透明度和模型裁剪，最后在同一任务内恢复完整画面。仅在按下与点击完成时读取少量像素，不在悬停或动画每帧读取。DPR 与 WebGL 纵轴分别换算。

无独立聊天按钮。键盘用户可以用 `Tab` 聚焦人物，再按 `Enter` 或空格触发 `touch_body`。每个动作使用下表对应的固定台词，气泡与回应状态同步。

## 动作与状态流程

| 过程 | 行为 |
| --- | --- |
| 待机 `idle` | 播放已有 `idle`；保留眨眼、呼吸和轻微视线跟随 |
| 注意 `noticing` | 有效交互后保留约 `240ms` 注意时间，同时按需加载所需动作 |
| 回应 `responding` | 播放对应的单次动作并显示台词；停止叠加鼠标视线，避免争抢头、眼、身体参数 |
| 恢复 `recovering` | 动作实际结束后清除台词，淡入待机约 `450ms`，再接受下一次交互 |

当前仅接入以下九个动作，动作组与原文件名一致：

| 触发 | 动作 | 约时长 | 对话 |
| --- | --- | --- | --- |
| 待机 | `idle` | `18.2s` | 无，循环播放 |
| 点击头部 | `touch_head` | `10.3s` | 你当人家还是小孩子吗？……痒痒的，诶，这就结束了？ |
| 点击胸部 | `touch_special` | `5.13s` | 诶！笨蛋！色狼！萝莉控！ |
| 点击其他身体部位 / 键盘互动 | `touch_body` | `7s` | 对人家来说，夜晚才刚刚开始呢，汝可不许说困了哦？ |
| 长时间未主动点击，随机三选一 | `main_1` | `7.87s` | 好无聊……阅读？没办法的啦。 |
| 同上 | `main_2` | `9.1s` | 喂喂，我们去做些快乐的事吧。 |
| 同上 | `main_3` | `10.17s` | 太平洋风平浪静？不，人家可不这样觉得。 |
| 从收起状态展开 | `home` | `6.07s` | 洗澡！然后进餐！咦，人家的葡萄酒呢？ |
| 点击工具栏邮箱链接 | `mail` | `5.13s` | 有话想对人家说？那就写封信吧，人家会期待的哦。 |

除 `idle` 外均为单次播放，资源中的淡入 `0.25s`、淡出 `0.35s`，保留原始关键帧。动作结束后返回循环待机。首次以展开状态加载页面不会触发 `home`；只有使用收起入口重新展开才播放，对话开启时同步显示出场台词。展开时先加载 `home`，运行时取消其首帧淡入并渲染初始姿态，随后才显示画布；不会先启动 `idle` 或等待 `240ms` 注意阶段。`idle` 仅提前加载用于结束后的恢复。若加载时仍被搜索、提示或后台状态隐藏，`home` 停留在首帧，实际显示时才开始播放和恢复计时。出场资源失败或超时则回退到 `idle`；减少动态效果模式直接显示静态待机。

`companionInactivityDelay` 当前为 `90000ms`。人物加载完成且可交互后开始计时，每次有效人物点击或键盘互动都会重新计时，包括动作播放期间的重复点击。到期且处于待机时，等概率随机触发 `main_1/main_2/main_3`；持续无互动时每隔同样时长再尝试一次，忙碌时不排队。鼠标移动、滚动和点击页面其他位置不会重置计时。搜索隐藏、复制提示、后台和关闭人物对话时取消计时，恢复后重新等待完整时长；收起（包括切换到处于收起状态的设备布局）会销毁计时器。

人物主动互动可以打断自动台词；邮箱入口优先播放 `mail`，并保留原生 `mailto:` 行为。连续人物点击不打断已有触摸回应，也不累积队列。其余动作不加入发布包；复制成功仅显示联系页已有提示，完成动作和完成事件接口已移除。`Expressions` 为空，继续使用动作本身的眼睛、嘴部等参数变化。

动作加载失败时保留短暂文字反馈，加载超时或结束事件缺失时有恢复上限。关闭人物对话、搜索隐藏、复制提示出现、后台暂停和收起都会取消当前回应；迟到的加载结果不会重播。减少动态效果模式不加载回应动作，仅保留文字反馈；`home` 在此模式下不播放，也不显示出场台词。

功能列提供人物点击对话开关，默认开启，偏好保存在浏览器中。关闭时立即隐藏当前气泡，并禁用人物的鼠标、键盘互动及自动对话。主动点击邮箱仍可触发 `mail`，展开仍触发 `home`，但对话关闭时不显示其气泡。收起再展开、桌面与手机切换和刷新后仍保留选择。

## 页面导览气泡

首次进入页面及切换到不同板块时，使用现有气泡显示一句介绍，约 `6s` 后消失。首页、关于、学习、项目和联系的台词统一维护在 `src/data/companion-introductions.ts`，沿用人物的「人家 / 汝」称呼。共享布局显式传入当前页面，不扫描正文；同一板块内滚动、点击锚点或重复点击当前导航不会重新触发，前进 / 后退到不同板块可以触发。

介绍只更新文字，不加载或切换动作，保持现有动画自然播放。连续切换仅显示最新页面的台词并重新计时。人物互动、邮箱和出场回应优先，本次介绍遇到这些回应时直接跳过；介绍期间仍可主动互动，互动会立即替换介绍。已有闲置动作继续播放，但旧台词不会在介绍结束后重新出现；介绍显示期间暂停闲置台词计时，结束后重新等待完整的闲置间隔。

看板娘收起、人物对话关闭、搜索打开、复制提示出现或页面处于后台时不显示介绍，恢复后不补播。首次展开状态下加载模型完成后可介绍当前页面；收起期间的页面访问会被丢弃，重新展开仍沿用原有出场行为。减少动态效果模式同样保留六秒文字介绍。

验证覆盖于 `tests/companion-behavior.test.ts` 与 `/tests/navigation-regression.html`：六秒计时、快速替换、动作连续性、互动优先、闲置台词抑制，以及关闭对话、搜索和收起后的不补播行为。

## 可复用的功能图标列

- 功能列位于人物右下侧的留白处，绝对定位，不改变模型大小。默认提供 GitHub 主页、Gmail 联系邮箱、人物点击对话开关和收起看板娘。
- GitHub 地址和邮箱复用站点现有配置；GitHub 在新标签页打开，邮箱使用 `mailto:` 唤起默认邮件应用并填写收件人。
- 图标按钮为 `24 × 24px`，SVG 为 `12 × 12px`，按钮间距为 `4px`；随人物缩小，同时保留可点击尺寸。对话关闭时使用带斜线的气泡图标、弱化颜色和对应文字说明。
- 鼠标进入人物所在矩形或图标列时显示：上沿从可见模型顶部向上留 `8px`，左右及底边沿用画布边界，排除对话框和画布顶部的多余留白。范围内包含人物周围的透明空隙及通往图标列的连续区域；停留或缓慢跨越空隙不会消失。离开整个范围后延迟 `240ms` 收起。扩展范围只用于悬停显示，透明区域仍然点击穿透且不会触发对话。
- 图标采用淡入、横向滑动和缩放，按顺序错开 `35ms`；悬停时轻微放大，并显示文字说明。隐藏期间不拦截点击。
- 键盘焦点同样可以显现图标列；鼠标普通点击留下的焦点不会让工具栏永久显示。
- `CompanionTools` 负责渲染，`CompanionAction` 区分动作与链接类型，并允许链接通过 `onSelect` 附加动作反馈，动作可通过 `pressed` 表达开关状态；`Live2DCompanion` 通过 `actions` 在默认功能后接收扩展项，再自动追加收起操作。

接入示例（仅演示扩展接口，不默认启用这些功能）：

```tsx
<Live2DCompanion
  suspended={isSearchOpen}
  actions={[
    {
      id: 'search',
      label: '搜索站内内容',
      icon: <SearchIcon />,
      onSelect: () => setIsSearchOpen(true),
    },
    {
      id: 'external',
      label: '访问外部主页',
      icon: <LinkIcon />,
      href: 'https://example.com/',
      external: true,
    },
  ]}
/>
```

使用唯一 `id` 和明确 `label`；图标用无障碍隐藏的 SVG。`href` 对应原生链接，可附加 `onSelect` 点击回调；不带 `href` 的 `onSelect` 对应原生按钮。外链新窗口带 `noopener noreferrer`。布局统一使用 `--companion-width`、`--companion-height` 和 `--companion-tool-size`，避免在各功能中重复写尺寸与动画。

## 资源与运行库

资源位于 `public/live2d/vampire`，仅使用模型、贴图、物理配置及上述九个动作。模型为吸血鬼（Vampire）的 `xixuegui_4`，来源与使用范围见随模型附带的 `SOURCE.md`。

- [模型来源页面](https://l2d.su/cn/skins/201233/)
- [pixi-live2d-display 文档](https://guansss.github.io/pixi-live2d-display/)

PixiJS 与适配库由 npm 锁定并按需打包。Cubism Core 在桌面展开时从 Live2D 官方地址加载，有十五秒超时与重试。加载中和失败时仍可收起；失败时可重试。状态提示距离内容视口右侧和底部各 `24px`（另计设备安全区），避免紧贴角落。

## 验证

- `npm run build`：类型检查及所有页面生产构建。
- `npm run lint`：组件、渲染代码及回归检查源码。
- `node --test tests/companion-behavior.test.ts`：资源清单、单次播放配置、固定台词、随机计时、重复点击重置、动作优先级、减少动画、延迟加载取消、失败与超时恢复（Node 24）。
- `node --test tests/routes.test.ts`：静态页面 URL、HTML 别名、查询 / 锚点、部署子路径及未知路径排除。
- `/tests/live2d-mobile-regression.html`：在小于 `768px` 的视口中检查实际手机 CSS、`32px` 按钮、展开后自动隐藏、触摸唤出、操作后重新计时、触摸离开事件、外部触摸 / 滚动 / 取消提前隐藏，以及页面控件优先与键盘可访问性。
- `/tests/live2d-inspect.html`：42 项真实模型的部位命中与不同 DPR / 缩放检查，可预览九个动作、冻结姿态并显示头部与身体的隔离画面；点击模型显示命中部位和模型坐标。`Check motion endings` 使用实际 Cubism 更新验证八个回应均能单次结束。只用于开发，不属于生产入口。
- 运行开发服务器后打开 `/tests/live2d-regression.html`：使用真实模型及 WebGL 检查移动端无资源请求、像素命中、气泡与可见轮廓间距及居中、右侧图标尺寸与视口边界、透明空间点击排除、透明区域长时间停留及缓慢移向工具栏、拖动取消、页面控件优先、键盘、默认链接、对话开关及偏好恢复、扩展动作与链接、搜索暂停、收起卸载及入口边距。测试会临时模拟媒体条件，结束后卸载场景并恢复偏好；该页面不在生产构建入口中。
- `/tests/navigation-regression.html`：真实站点及 WebGL 下检查五个页面切换时的画布身份、资源请求次数和动作连续性，以及前进 / 后退、滚动恢复、搜索锚点、原生链接行为和收起状态保留。浏览器回归页面应分别运行，保持被测页面处于前台，避免后台暂停影响计时检查。
- `/tests/live2d-bounds.html`：在三种布局尺寸和 `1 / 1.5 / 2` DPR 下，用扩大后的探测画布逐帧验证两个完整 idle 循环（含半透明边缘）均未裁切，并验证 `home` 与 `idle` 使用相同缩放、位置及画布尺寸，动画衔接时不发生额外布局变化。
- 浏览器人工复核桌面和手机宽度、深浅主题、气泡出现、功能图标与模型间移动、展开/收起、刷新恢复，以及滚动后的页面操作。

页面回归覆盖头部 / 胸部 / 其他部位及对应台词、邮箱动作、无对白展开、真实闲置计时、背景排除、完整动作恢复和复制提示。测试中的减少动态效果设置同时同步到 CSS，避免把气泡入场动画的中间帧误当成最终布局。
