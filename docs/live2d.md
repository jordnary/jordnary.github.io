# Live2D 看板娘

看板娘在共享的 `SiteLayout` 中接入，覆盖首页、关于、学习、项目和联系页面。

## 显示与尺寸

- 仅面向桌面：小于 `768px`、主要指针为触摸或不支持悬停时，整个组件不挂载，包括展开入口；首次进入手机页面不会请求渲染库、Cubism Core 和模型资源。切换到该设备条件时会销毁已加载的场景。
- 桌面默认展开；收起偏好保存在浏览器中。收起会卸载画布、停止动画并释放 GPU 资源，右下角保留一个小图标用于恢复。
- 默认画布宽度为 `clamp(17rem, 24vw, 21rem)`，即约 `272–336px`；高度为 `min(29rem, 58svh)`，上限约 `464px`。相较初版上限 `200 × 280px` 明显放大。短窗口另做适配。
- 按实际渲染透明度校正模型导出留白，等比显示完整模型。气泡绝对定位，可与模型上部重叠，不再挤占人物高度。
- 搜索打开时隐藏并暂停；复制提示出现时隐藏且不接受人物交互；窗口转入后台暂停。系统减少动态效果设置会停用人物动画及控件过渡。

## 严格的聊天触发范围

聊天的鼠标命中范围定义为：**当前模型画面中 alpha 不低于 `24/255` 的像素**。范围包括模型本身可见的头发、服装、饰物和背景装饰，不包括透明留白、内部透明孔洞及 CSS 投影；不使用画布矩形或固定人物矩形代替判定。

一次有效聊天需要同时满足：

1. 主要鼠标指针的左键单击，未按 `Ctrl`、`Meta`、`Alt`、`Shift`，且事件未被网页取消。
2. 按下和单击完成时均命中上述可见像素；中途移动不得超过 `6 CSS px`。拖出再拖回、滚动和指针取消都会终止候选点击。
3. 没有选中的页面文字，且目标不是链接、按钮、输入框、可编辑区、可聚焦控件或常用 ARIA 交互控件。
4. 看板娘已经加载、未被搜索或复制提示隐藏，且页面处于可见状态。

画布保持点击穿透，网页原有控件保留优先级。像素读取前重新渲染当前姿态，并做设备像素比例及 WebGL 纵轴换算，避免动作变化后旧轮廓误触。鼠标悬停检测最高约 `20Hz`，仅读取一个像素；不会逐帧复制整幅图像。

无独立的聊天按钮。键盘用户可以用 `Tab` 聚焦人物，再按 `Enter` 或空格聊天。人物点击播放已有摸头动作，切换本站编写的短句；五秒后气泡消失。

## 可复用的功能图标列

- 功能列位于人物左侧，绝对定位，不改变模型大小。当前只有「收起看板娘」。
- 鼠标命中可见模型时显示；移到图标列可继续操作。离开两者后延迟 `240ms` 收起，给跨越透明间隙留出时间。
- 图标采用淡入、横向滑动和缩放，按顺序错开 `35ms`；悬停时轻微放大，并显示文字说明。隐藏期间不拦截点击。
- 键盘焦点同样可以显现图标列；鼠标普通点击留下的焦点不会让工具栏永久显示。
- `CompanionTools` 负责渲染，`CompanionAction` 为动作和链接提供互斥类型；`Live2DCompanion` 通过 `actions` 接收扩展项，再自动追加收起操作。

接入示例（仅演示扩展接口，不默认启用这些功能）：

```tsx
<Live2DCompanion
  suspended={isSearchOpen}
  actions={[
    {
      id: 'search',
      label: '搜索站内内容',
      icon: <SearchIcon />,
      onSelect: () => setIsSearchOpen(true),
    },
    {
      id: 'external',
      label: '访问外部主页',
      icon: <LinkIcon />,
      href: 'https://example.com/',
      external: true,
    },
  ]}
/>
```

使用唯一 `id` 和明确 `label`；图标用无障碍隐藏的 SVG。`href` 对应原生链接，`onSelect` 对应原生按钮。外链新窗口带 `noopener noreferrer`。布局统一使用 `--companion-width`、`--companion-height` 和 `--companion-tool-size`，避免在各功能中重复写尺寸与动画。

## 返回顶部清理

没有返回顶部按钮、事件、样式或工具栏入口；共享布局中残留的 `top` 锚点也已删除。正文的章节定位和阅读进度属于现有导航能力，继续保留。

## 资源与运行库

资源位于 `public/live2d/vampire`，仅使用模型、贴图、物理配置、待机和摸头动作。模型为吸血鬼（Vampire）的 `xixuegui_4`，来源与使用范围见随模型附带的 `SOURCE.md`。

- [模型来源页面](https://l2d.su/cn/skins/201233/)
- [pixi-live2d-display 文档](https://guansss.github.io/pixi-live2d-display/)
- [Live2D Cubism SDK for Web](https://www.live2d.com/sdk/download/web/)

PixiJS 与适配库由 npm 锁定并按需打包。Cubism Core 在桌面展开时从 Live2D 官方地址加载，有十五秒超时与重试。加载中和失败时仍可收起；失败时可重试。

## 验证

- `npm run build`：类型检查及所有页面生产构建。
- `npm run lint`：组件、渲染代码及回归检查源码。
- 运行开发服务器后打开 `/tests/live2d-regression.html`：使用真实模型及 WebGL 检查移动端无资源请求、像素命中、透明空间排除、悬停跨越、拖动取消、页面控件优先、键盘、扩展动作与链接、搜索暂停、收起卸载和偏好保留。测试会临时模拟媒体条件，结束后卸载场景并恢复偏好；该页面不在生产构建入口中。
- 浏览器人工复核桌面和手机宽度、深浅主题、气泡出现、功能图标与模型间移动、展开/收起、刷新恢复，以及滚动后的页面操作。

进阶路线见 [看板娘进阶建议](./live2d-roadmap.md)。
