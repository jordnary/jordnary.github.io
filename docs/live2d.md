# Live2D 看板娘

看板娘在共享的 `SiteLayout` 中接入，覆盖首页、关于、学习、项目和联系页面。

## 显示与尺寸

- 仅面向桌面：小于 `768px`、主要指针为触摸或不支持悬停时，整个组件不挂载，包括展开入口；首次进入手机页面不会请求渲染库、Cubism Core 和模型资源。切换到该设备条件时会销毁已加载的场景。
- 桌面默认展开；收起偏好保存在浏览器中。收起会卸载画布、停止动画并释放 GPU 资源，右下角保留一个 `44 × 44px` 的小图标用于恢复，距内容视口右侧和底部各 `24px`（另计设备安全区），独立于展开时的定位。
- 默认画布宽度为 `clamp(12rem, 18vw, 15rem)`，即约 `192–240px`；高度为 `min(21rem, 46svh)`，上限约 `336px`。按参考图缩至此前约七成，短窗口随可用高度等比缩小。
- 按实际渲染透明度校正模型导出留白，等比显示完整模型。气泡根据可见模型边界水平居中，底边距离模型上沿约 `10px`；宽度上限 `200px`，并随可见模型宽度收窄，文字为 `13px`。窗口尺寸变化时同步更新定位，不挤占人物高度或超出右侧视口。
- 功能列放在人物右下侧的透明区域，不在画布外额外占位；距画布右侧 `16px`、底边 `8px`。画布距离内容视口右侧 `2px`、下侧 `6px`（另计设备安全区），相对此前向右移动 `4px`，模型在画布内靠右下对齐。
- 搜索打开时隐藏并暂停；复制提示出现时隐藏且不接受人物交互；窗口转入后台暂停。系统减少动态效果设置会停用人物动画及控件过渡。

## 严格的聊天触发范围

鼠标命中以当前姿态的语义部件为准，并要求实际渲染 alpha 不低于 `24/255`：

- **摸头**：模型自带 `TouchHead` 三角网格与实际头部可见像素的交集。
- **招呼**：身体、服装和四肢的可见像素；键盘 `Enter` / 空格同样触发招呼。
- **操作完成**：没有人物点击区域，只接受页面显式报告的成功事件。

模型原始 `TouchBody` 矩形包含大量背景，因此不采用它作为身体范围。实际部件按导出的父级关系识别，优先识别 `shenti`，再识别 `tou`；模型把身体嵌套在头部层级下，不能简单地把 `tou` 的所有后代都算作头部。另按逐网格预览结果排除混在身体与面部层级里的翅膀、翼骨、长飘带和手持装饰。背景、外围装饰、透明孔洞和 CSS 阴影不触发反应。

一次有效聊天需要同时满足：

1. 主要鼠标指针的左键单击，未按 `Ctrl`、`Meta`、`Alt`、`Shift`，且事件未被网页取消。
2. 按下和单击完成时均命中同一语义区域；中途移动不得超过 `6 CSS px`。从头部滑到身体、拖出再拖回、滚动和指针取消都会终止候选点击。
3. 没有选中的页面文字，且目标不是链接、按钮、输入框、可编辑区、可聚焦控件或常用 ARIA 交互控件。
4. 人物点击对话已开启，看板娘已经加载、未被搜索或复制提示隐藏，且页面处于可见状态。

画布保持点击穿透，网页原有控件保留优先级。命中时通过 Pixi 与 Cubism 的逆变换换算坐标，使用当前帧网格；通过短暂隔离语义部件的渲染透明度排除背景，包含贴图透明度和模型裁剪，最后在同一任务内恢复完整画面。仅在按下与点击完成时读取少量像素，不在悬停或动画每帧读取。DPR 与 WebGL 纵轴分别换算。

无独立聊天按钮。键盘用户可以用 `Tab` 聚焦人物，再按 `Enter` 或空格打招呼。摸头与招呼各自使用独立短句，气泡与回应状态同步。

## 动作与状态流程

| 过程 | 行为 |
| --- | --- |
| 待机 `idle` | 播放已有 `Idle`；保留眨眼、呼吸和轻微视线跟随 |
| 注意 `noticing` | 有效交互后保留约 `240ms` 注意时间，同时按需加载所需动作 |
| 回应 `responding` | 播放对应的单次动作并显示台词；停止叠加鼠标视线，避免争抢头、眼、身体参数 |
| 恢复 `recovering` | 动作实际结束后清除台词，淡入待机约 `450ms`，再接受下一次交互 |

当前动作素材已经核对：

| 用途 | 原文件 | 时长 | 处理 |
| --- | --- | --- | --- |
| 待机 | `idle.motion3.json` | `18.2s` | 循环 |
| 摸头 | `touch_head.motion3.json` | `10.3s` | 单次，独立摸头台词 |
| 招呼 | `main_1.motion3.json` | `7.87s` | 单次，普通交流台词 |
| 完成 | `mission_complete.motion3.json` | `6.1s` | 单次，使用操作成功的反馈文案 |

原始包共 15 个动作；原始回应均标记为循环，因此发布副本改为单次并设置淡入淡出，保留关键帧。`home/login` 有人物缩小和重新入场过程，不适合反复点击招呼；其余未使用动作不加入发布包。`Expressions` 确实为空，本次使用动作本身的眼睛、嘴部等参数变化，没有创建虚构表情名称。

回应期间忽略连点及自动完成提示，不累积队列；完成提示另有 `15s` 冷却。动作加载失败时保留短暂文字反馈，加载超时或结束事件缺失时有恢复上限。关闭对话、搜索隐藏、复制提示出现、后台暂停和收起都会取消当前回应；迟到的加载结果不会重播。减少动态效果模式不加载回应动作，只显示短暂文字并恢复待机。

页面成功后可调用 `notifyCompanionComplete(message)`。联系页已接入：剪贴板成功后先显示现有复制提示，提示卸载后再由看板娘回应；复制失败显示失败提示，不触发完成动作。打开外链、点击工具按钮、失败或未完成的操作都不会被自动当作成功。

功能列提供人物点击对话开关，默认开启，偏好保存在浏览器中。关闭时立即隐藏气泡，并禁用鼠标与键盘触发的对话和摸头动作；悬停菜单、链接及收起功能保持可用。收起再展开、桌面与手机切换和刷新后仍保留选择。

## 可复用的功能图标列

- 功能列位于人物右下侧的留白处，绝对定位，不改变模型大小。默认提供 GitHub 主页、Gmail 联系邮箱、人物点击对话开关和收起看板娘。
- GitHub 地址和邮箱复用站点现有配置；GitHub 在新标签页打开，邮箱使用 `mailto:` 唤起默认邮件应用并填写收件人。
- 图标按钮为 `24 × 24px`，SVG 为 `12 × 12px`，按钮间距为 `4px`；随人物缩小，同时保留可点击尺寸。对话关闭时使用带斜线的气泡图标、弱化颜色和对应文字说明。
- 鼠标进入人物画布矩形或图标列时显示，包含人物、透明留白及通往图标列的连续区域；停留或缓慢跨越空隙不会消失。离开整个范围后延迟 `240ms` 收起。扩展范围只用于悬停显示，透明区域仍然点击穿透且不会触发对话。
- 图标采用淡入、横向滑动和缩放，按顺序错开 `35ms`；悬停时轻微放大，并显示文字说明。隐藏期间不拦截点击。
- 键盘焦点同样可以显现图标列；鼠标普通点击留下的焦点不会让工具栏永久显示。
- `CompanionTools` 负责渲染，`CompanionAction` 为动作和链接提供互斥类型，动作可通过 `pressed` 表达开关状态；`Live2DCompanion` 通过 `actions` 在默认功能后接收扩展项，再自动追加收起操作。

接入示例（仅演示扩展接口，不默认启用这些功能）：

```tsx
<Live2DCompanion
  suspended={isSearchOpen}
  actions={[
    {
      id: 'search',
      label: '搜索站内内容',
      icon: <SearchIcon />,
      onSelect: () => setIsSearchOpen(true),
    },
    {
      id: 'external',
      label: '访问外部主页',
      icon: <LinkIcon />,
      href: 'https://example.com/',
      external: true,
    },
  ]}
/>
```

使用唯一 `id` 和明确 `label`；图标用无障碍隐藏的 SVG。`href` 对应原生链接，`onSelect` 对应原生按钮。外链新窗口带 `noopener noreferrer`。布局统一使用 `--companion-width`、`--companion-height` 和 `--companion-tool-size`，避免在各功能中重复写尺寸与动画。

## 验证

- `npm run build`：类型检查及所有页面生产构建。
- `npm run lint`：组件、渲染代码及回归检查源码。
- `node --test tests/companion-behavior.test.ts`：状态流程、重复输入、完成冷却、减少动画、延迟加载取消、失败与超时恢复（Node 24）。
- `/tests/live2d-inspect.html`：36 项真实模型的部位命中与不同 DPR / 缩放检查，可预览四个动作、冻结姿态并显示头部与身体的隔离画面；点击模型显示命中部位和模型坐标。`Check motion endings` 使用实际 Cubism 更新验证三个回应均能单次结束。只用于开发，不属于生产入口。
- 运行开发服务器后打开 `/tests/live2d-regression.html`：使用真实模型及 WebGL 检查移动端无资源请求、像素命中、气泡与可见轮廓间距及居中、右侧图标尺寸与视口边界、透明空间点击排除、透明区域长时间停留及缓慢移向工具栏、拖动取消、页面控件优先、键盘、默认链接、对话开关及偏好恢复、扩展动作与链接、搜索暂停、收起卸载及入口边距。测试会临时模拟媒体条件，结束后卸载场景并恢复偏好；该页面不在生产构建入口中。
- 浏览器人工复核桌面和手机宽度、深浅主题、气泡出现、功能图标与模型间移动、展开/收起、刷新恢复，以及滚动后的页面操作。

本次回归通过 67 项页面检查，包含独立摸头、身体招呼、背景排除、完整动作恢复、复制等待/成功/失败及提示时序。测试中的减少动态效果设置同时同步到 CSS，避免把气泡入场动画的中间帧误当成最终布局。
