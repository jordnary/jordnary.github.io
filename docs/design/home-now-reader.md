# Now & notes：林间手记

首页近况卡片打开原生 dialog，展示同源 GitHub 与 RSS 内容。文字与控件保持原生 HTML，背景插画只承担装饰。

## 布局与素材

- 阅读窗口在桌面和手机上均保持横向 3:2，宽高同时受视口限制；背景完整展示，不拉伸或裁切。
- 背景使用 `public/images/home/now-woodland-frame.webp`，卷草花纹使用 `repository-flourish.webp`。插画保留透明通道，不包含源元数据。
- 中文使用 Woodland WenKai，英文标题使用 Instrument Serif。字体分包与生成方式见 `public/fonts/README.md`。
- 正文内部滚动，关闭按钮保留至少 44px 点击区，支持 Escape、背景点击和焦点归还。

## 动效与滚动

打开和关闭使用来源卡片的实际几何信息，通过 transform 与 opacity 过渡。提前关闭、重复操作和窗口变化须从当前状态继续或安全结束；减少动态效果时直接切换。

滚动锁保留背景滚动条和页面布局。滚轮、触控与滚动键仅作用于阅读区；关闭时清理监听器，恢复焦点和页面位置。

卷草花纹位于仓库条目右下沿，悬停或键盘聚焦时从左向右展开，离开时同向擦除。快速重新进入时先清除剩余部分，再重新展开，避免反向恢复或执行过期动画。

## 验证

启动对应测试服务后运行 `npm run test:home-now`，覆盖：

- 多尺寸布局、字体、数据加载与错误恢复。
- 动画中断、重复 Escape 和窗口变化。
- 经典或覆盖式滚动条下的页面位置与滚动锁。
- 焦点归还、快速开关以及花纹显隐方向。
